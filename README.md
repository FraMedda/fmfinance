# fmfinance 

A professional Python package by **Francesco Medda** to fetch and clean financial data from the **Kenneth French Data Library** and the **St. Louis FED (FRED)**.

## Main Features
- **FFReader**: Download and parse Fama-French/Carhart factor models.
- **FFSearch**: Search for available datasets in the Dartmouth library.
- **FredReader**: Access economic data from FRED with built-in rate limiting (cooldown).
